# Haskell Tennis Kata

## Setup 
### Local
1. Install [GHCup](https://www.haskell.org/ghcup/) - the Haskell toolchain installer.
2. Install GHC (Haskell compiler). Any version should work:
    ```bash
    ghcup install ghc
    ghcup set ghc
    ```
3. Compile and run in one step:
    ```bash
    runghc Test.hs
    ```

### Online
Alternatively, paste the `.hs`s to [Haskell Playground](https://play.haskell.org/).
